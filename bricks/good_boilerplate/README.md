# good_boilerplate

[![Powered by Mason](https://img.shields.io/endpoint?url=https%3A%2F%2Ftinyurl.com%2Fmason-badge)](https://github.com/felangel/mason)

A Flutter starter project brick with flavors, routing, Cubit state management, Dio networking, dependency injection, reusable theme tokens, and onboarding.

The post-generation hook runs `flutter create` to add `android`, `ios`, `web`, and `macos` platform folders, then patches native metadata from the Mason variables.

## Usage

From the Mason workspace:

```sh
mason get
mason make good_boilerplate -q
```

After the brick is published to BrickHub, install it globally once:

```sh
mason add -g good_boilerplate
```

Or register the local brick globally before publishing:

```sh
mason add -g good_boilerplate --path /Users/zianfahrudy/Documents/ZIANDEV/good_boilerplate_cli/bricks/good_boilerplate
```

Then run from any target output folder:

```sh
mason make good_boilerplate -q
```

Example with custom app metadata via `config.json`:

```json
{
  "project_name": "my_app",
  "app_id": "id.ziandev.my_app",
  "app_name": "My App",
  "description": "A production-ready Flutter starter.",
  "theme_style": "neubrutalism"
}
```

```sh
mason make good_boilerplate -q -c config.json
```

## Variables

- `project_name`: Dart package name for the generated project.
- `app_name`: Display name shown in the generated app.
- `app_id`: Application id stored in the generated app config.
- `description`: Pubspec description.
- `theme_style`: `soft_pastel` (default) or `neubrutalism`.

## Included

- Flutter `>=3.47.0` and Dart SDK `^3.13.0`.
- Dev and prod app flavor entry points: `lib/main_dev.dart` and `lib/main_prod.dart`.
- Native Flutter platform folders generated by `flutter create`: `android`, `ios`, `web`, and `macos`.
- VS Code launch configurations for dev and prod.
- `AppConfig` for app id, per-flavor API base URL, network logging, upgrade checks, Wiredash, and RevenueCat offerings.
- Dio with `talker_dio_logger`.
- BLoC Cubit with `flutter_bloc`.
- GoRouter navigation.
- `cached_network_image` wrapper widget.
- `get_it` dependency injection.
- `upgrader` `13.6.0` wrapper for app-store update prompts.
- `shorebird_code_push` `2.0.7` startup check that downloads available patches without blocking app launch.
- `wiredash` `2.6.1` root integration and Settings feedback launcher.
- `json_serializable` and `json_annotation` example model.
- Three-slide reusable onboarding screen with stepper, headline, subheadline, illustration, button, and trusted info.
- Settings screen with dark/light mode powered by Cubit and `shared_preferences`, plus a Feedback section.
- Paywall screen with logo, benefits, RevenueCat plans, dummy fallback plans, free-trial selection, delayed close button, restore, terms, and privacy links.
- Daily quota service using local storage for per-feature usage limits.
- RevenueCat service configured from `AppConfig.revenueCat` with `default` and `promo_offer` offering identifiers.
- AdMob service configured from `AppConfig.adMob`, including banner, interstitial, and rewarded helpers.
- Selectable soft-pastel or neubrutalism theme; the latter uses `neubrutalism_ui` `2.0.2` components.

Do not use `--no-hooks` if you want native platform folders.

Use `-q` when generating if you want Mason to hide the long per-file `created ...` list and keep the output concise.
